# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/axitdev/phpunit-ai-evals/security/advisories/new) rather than in a public issue. Expect a first reply within a week.

## Scope

This is a test-time library. The most likely issues are secrets leaking into committed cassettes, or API keys being sent to the wrong host. See [Secrets](docs/how-it-works.md#secrets) for what is redacted today.
